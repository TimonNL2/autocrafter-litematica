First experimental release for **Minecraft Java 26.3**, **Fabric Loader 0.19.5+**, **Fabric API 0.162.0+26.3** and **Java 25**.

Download `autocrafter-litematica-0.1.0-alpha.1.jar` and place it in your client `mods` folder alongside Fabric API. Do not install the `-sources.jar` as a mod. The server does not need this mod. Litematica is optional.

Press **K** to open the workshop, **U** to select region corners and **O** to stop a task. See the README for setup and building from source.

This alpha includes material import, region selection, storage scans, recursive crafting plans and reviewed small-batch crafting into a selected output chest or already-placed shulker. The executor requires an empty main inventory and offhand, at most nine source stacks, and reachable storage/workstations. It reopens containers to verify server state after each transaction.

**Not included yet:** automatically placing/mining/recovering packed shulkers, automatic walking, sorting policies, non-crafting workstations and direct Litematica API integration. Packed shulker contents are never counted as accessible loose resources. Products, surplus and remainders go to the same reviewed output container.

This is an experimental prerelease, not the completed full automation specification. The repository includes automated tests and a manual multiplayer validation checklist. Keep old releases to return to an earlier version; each tag contains the corresponding buildable source.
