# Autocrafter Litematica 0.2.0-beta.2

Minecraft Java **26.3**, Java **25**, Fabric Loader **0.19.5+**, Fabric API **0.162.0+26.3**.

## Mouse region selection

Open **K → Storage → + Input / Output / Work**. Left-click a block to set the first corner, then right-click another block to save the region box. Left-click again to replace the first corner before finishing. For **+ Staging**, click the support block with either button.

While selecting, these clicks do not break blocks, use held items or open containers. Outside selection mode, the mouse works normally. The U key remains available as an alternative.

Includes all shulker automation, sorting and result reports from beta.1. Existing operating limits still apply: empty main inventory/offhand, reachable storage and at most 27 occupied job-buffer slots. Dedicated-server latency testing remains outstanding.

Older beta and alpha releases remain available unchanged.
