# Autocrafter Litematica 0.3.0-beta.1

For Minecraft Java **26.3**, Java **25**, Fabric Loader **0.19.5+** and Fabric API **0.162.0+26.3**.

**New required client dependency:** install [Baritone API Fabric 1.20.0](https://github.com/cabaletta/baritone/releases/download/v1.20.0/baritone-api-fabric-1.20.0.jar) in your mods directory alongside this mod and Fabric API. Baritone is downloaded separately from its official project; do not use builds for other Minecraft versions.

## Changes

- Baritone walks to selected containers/crafting tables and rotates the player toward each interaction.
- Automatic approach and accurate standing position at shulker Staging.
- Baritone background cache workers no longer prevent the client from shutting down normally.
- Scan progress and actual failure reasons are visible. Pressing Stop after a completed scan keeps it valid. Build plan and Review moves explain which step is still required.
- All required stacks from a source container are collected during one opening session. One server-confirmed reopen follows the complete batch, instead of reopening after every stack.

## Survival without OP

The mod needs no OP, cheats, command permissions or server plugin. It uses ordinary walking, block interactions, crafting and inventory actions. The integration fixture removes player command permissions and runs the workshop in survival. Commands visible in the test harness only prepare the temporary test world; production code does not send them.

Containers must be accessible to your player. Region protection and server restrictions are respected. Workshop navigation does not break or place blocks to make a route. Keep walkways and Staging clear, and selected regions loaded. Stop any unrelated Baritone task before starting a workshop operation.

Existing empty-inventory and 27-slot job-capacity checks remain. All previous releases remain available. Dedicated-server latency testing remains outstanding.
