# Autocrafter Litematica 0.2.0-beta.1

For Minecraft Java **26.3**, Java **25**, Fabric Loader **0.19.5+** and Fabric API **0.162.0+26.3**. Install the JAR without `-sources` in your client mods directory.

## New in this beta

- Automatic handling of input and output shulkers stored in chests: place, open, recover and return to the original slot.
- Reviewed physical scans for unknown shulker contents.
- Mixed output or one item type per reserved output container; packed output shulkers are preferred.
- Persistent recovery records and **Activity → Recover box** after an interruption.
- **Activity → Result report / Copy report**: requested, delivered and uncompleted quantities, plus raw materials still needed. Reports also save locally.
- Correct shared-stock and batch-surplus accounting in shortage lists, and output reservations for crafting remainders.

## Setup and limits

Select Input, Output and Work regions, plus a clear staging position on a solid non-interactive floor. Stand beside Staging, within 1.6 blocks of its centre. Scan storage, inspect unknown boxes, build a plan, review movements and confirm. Choose automatic or scan-only shulker use in Settings.

Your main inventory and offhand must be empty. Preflight requires enough output space and keeps at least nine job-buffer slots free for handling. Split jobs requiring more than 27 occupied inventory slots. All selected storage and the crafting table must be reachable; there is no storage pathfinding. Only known supported craftingtable recipes are used; no smelting, brewing or stonecutting.

Safe stop returns the current shulker and leaves job items in your inventory. Unexpected changes stop actions and preserve recovery information; never blindly resume an interrupted task. Dedicated-server latency testing remains outstanding, so this release is labelled beta.

Source code, Gradle wrapper and build instructions are included in the repository. Previous alpha downloads and their original tag remain available unchanged.
